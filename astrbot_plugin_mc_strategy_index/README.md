# MC公会萌新攻略索引机器人

面向 MC 服务器公会社群的轻量化攻略索引机器人，核心服务场景为公会社群萌新自助查攻略、管理员自动化运维攻略库。

## 核心闭环

> **人工上传收录 → 机器自动建库 → 管理员巡检纠错 → AI 图片标准化整改 → 萌新看图/关键词检索**

无内置预设攻略资源，所有攻略资源由人工收集上传，支持文字 TXT、图片格式资源批量导入。

---

## 功能概览

| 模块 | 说明 |
|------|------|
| **资源上传 & 自动建库** | 单文件/批量 ZIP 上传，自动解析 TXT/图片，智能分类预识别，未识别标记为"待整改" |
| **严格匹配触发词** | 用户发送触发词即自动返回对应攻略（文字+全部图片），类似关键词自动回复但为**完全匹配** |
| **萌新关键词检索** | `/攻略 <关键词>` 支持模糊/精确匹配，图文同步输出，无结果时提示纠错 |
| **管理员巡检** | `/巡检攻略` 全库筛查无分类/无触发词/无图片等异常，生成详细报告 |
| **图片整改** | `/整改攻略` 调用 AI 图片编辑 API 标准化攻略图片（支持 OpenAI/豆包） |
| **资源增删改查** | 单条/批量删除、编辑元数据、替换图片、分类管理，全操作日志记录 |
| **攻略索引图** | `/索引` 返回含全部触发词的 AI 生成索引引导图，新增/巡检后自动更新 |
| **WebUI 管理面板** | 可视化控制台，支持攻略 CRUD、多图上传管理、关键词/触发词编辑 |

## 命令列表

### 公开命令

| 命令 | 用法 | 说明 |
|------|------|------|
| `/攻略 <关键词>` | `/攻略 钻石` | 模糊搜索攻略 |
| `/攻略列表 [分类]` | `/攻略列表 战斗技巧` | 按分类查看攻略 |
| `/索引` | `/索引` | 查看全部触发词+索引图 |
| `触发词` | 直接发送 `末影龙攻略` | 严格匹配触发词，自动返回攻略图文 |

### 管理员命令

| 命令 | 用法 | 说明 |
|------|------|------|
| `/上传攻略` | `/上传攻略 钻石挖矿指南 钻石,挖矿攻略 资源收集` + 图片 | 上传单篇攻略（可附带多张图片） |
| `/上传攻略 批量` | `/上传攻略 批量` + ZIP 文件 | 批量导入攻略包 |
| `/巡检攻略` | `/巡检攻略` | 巡查全库异常资源（自动更新索引图） |
| `/整改攻略 <序号>` | `/整改攻略 1` | 调用 AI 整改指定攻略图片 |
| `/编辑攻略 <序号> <字段> <值>` | `/编辑攻略 1 trigger_words 钻石,挖矿` | 修改攻略元数据 |
| `/删除攻略 <序号>` | `/删除攻略 1` | 删除攻略及关联图片 |
| `/替换攻略图 <序号>` | `/替换攻略图 1` + 图片 | 替换攻略图片（可多张） |
| `/攻略分类管理` | `/攻略分类管理 add 新分类` | 管理攻略分类 |
| `/攻略日志 [条数]` | `/攻略日志 20` | 查看操作日志 |

## 配置项

| 配置 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `admin_whitelist` | list | `[]` | 管理员白名单用户 ID |
| `notify_permission_denied` | bool | `true` | 无权限时发送提示 |
| `enable_image_edit` | bool | `false` | 启用 AI 图片编辑 |
| `image_api_provider` | string | `openai` | API 提供商 (openai/doubao) |
| `image_api_key` | string | `""` | API 密钥 |
| `image_api_base_url` | string | `https://api.openai.com` | API 地址 |
| `image_api_model` | string | `gpt-4o` | 模型名称 |
| `search_fuzzy_match` | bool | `true` | 模糊匹配开关 |
| `quote_reply` | bool | `true` | 引用回复开关 |
| `max_image_size_kb` | int | `5120` | 图片大小上限 (KB) |

## 使用流程

### 管理员首次部署

1. 在 AstrBot 插件市场安装或手动放入插件目录
2. 在插件配置中设置 `admin_whitelist`（你的 QQ 号）
3. （可选）配置 `image_api_key` 启用 AI 图片整改功能
4. 重启机器人

### 收录攻略

```
/上传攻略 钻石挖矿指南 钻石攻略,挖钻石 资源收集
[附带攻略图片1] [附带攻略图片2] ...
```

- 攻略名称：`钻石挖矿指南`
- 触发词：`钻石攻略`, `挖钻石`（用户发这些词即返回本攻略）
- 分类：`资源收集`
- 图片可发多张，全部收录

### 萌新使用

```
/索引              → 查看全部可用触发词和索引图
/攻略 钻石         → 搜索钻石相关攻略
钻石攻略           → 直接发送触发词，自动返回图文攻略
```

### 管理员维护

```
/巡检攻略          → 巡检全库并自动更新索引图
/整改攻略 1        → AI 整改第 1 篇攻略的图片
/编辑攻略 1 trigger_words 钻石,挖矿,Y11
/删除攻略 1
```
